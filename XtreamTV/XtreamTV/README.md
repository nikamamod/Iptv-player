Build: open this folder in Android Studio (Koala+), let Gradle sync, then
Build > Build APK(s)  ->  app/build/outputs/apk/debug/app-debug.apk
Live streams use .m3u8; change to .ts in Api.kt (fun url) if your provider needs it.

No Android Studio? Push this folder to a new GitHub repo; Actions tab > "Build APK" > download artifact XtreamTV-apk.
